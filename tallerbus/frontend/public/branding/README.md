# Logotipo de Terrabus

El rediseño visual del login utiliza archivos locales de esta carpeta. El archivo original del logotipo todavía no está disponible en el workspace: las imágenes se recibieron como referencias visibles en el chat, sin un archivo descargable. No se incluye un logo recreado ni una imagen rota.

Cuando esté disponible el original, guardarlo como `terrabus-logo.png` sin redibujarlo ni cambiar colores y asignar `/branding/terrabus-logo.png` a `LoginComponent.logoUrl`. El CSS ya contempla sus proporciones, posición y adaptación a móvil. Esta propiedad es únicamente de presentación; la autenticación se conserva.
